Build a complete **hackathon-ready MVP web app** called **NutriRecover** — an AI-assisted **nutritional deficiency recovery support platform**.

## Product Goal

NutriRecover should help users with **suspected or diagnosed nutritional deficiencies** understand whether their **daily meals are supporting recovery**. It should bridge the gap between **symptoms / optional lab reports** and **daily food tracking + recovery-focused meal planning**.

The app must:

1. Take **symptoms + optional lab values + user profile**
2. Infer likely **nutrient recovery focus areas** (not medical diagnosis)
3. Generate a **30–40 day food-based recovery plan**
4. Let users **log daily meals**
5. Compare intake vs **daily recovery nutrient targets**
6. Detect missed targets and give **next-day food additions/substitutions**
7. Show **progress dashboards**
8. Optionally compare **baseline vs follow-up lab values**

---

# Important Rules

* This is a **nutrition recovery support app**, **not a diagnosis tool**.
* Use phrases like:

  * “possible nutrient gap”
  * “recovery nutrition support”
  * “dietary recovery target”
* Avoid saying the app diagnoses disease.
* Add a disclaimer in the UI:

  > NutriRecover is a food-based nutritional recovery support tool and does not replace professional medical advice, diagnosis, or treatment.

# Core Features

## 1) Intake / Assessment

Create a form to collect:

* name, age, gender, height, weight
* diet type: vegetarian / eggetarian / non-vegetarian / vegan
* allergies / restrictions
* cuisine preference / budget (optional)

### Symptoms checklist

Include symptoms like:

* fatigue, weakness, hair fall, pale skin, dizziness, muscle cramps, bone pain, poor immunity, tingling/numbness, brain fog, poor appetite, brittle nails, slow recovery, low energy

### Optional lab inputs

* hemoglobin
* ferritin
* vitamin B12
* vitamin D
* serum calcium
* total protein / albumin

### Output

Infer **recovery focus areas** such as:

* possible iron recovery support needed
* likely low protein intake risk
* B12 support recommended
* calcium intake improvement recommended
* vitamin D support recommended

Do **not** call it a diagnosis.

---

## 2) Recovery Engine

Build a **rule-based nutrient recovery engine** that maps symptoms + labs + user profile into nutrient priorities.

For each nutrient:

* assign a **priority score**
* assign **high / medium / low priority**
* define **daily recovery target**
* generate **reasoning**
* attach recommended foods

Example logic:

* fatigue + low hemoglobin/ferritin → iron priority up
* vegetarian + fatigue + low B12 → B12 priority up
* weakness + low protein / underweight → protein priority up
* bone pain / cramps / low calcium → calcium priority up
* low vitamin D / poor sunlight support → vitamin D support flag

Return a structured output like:

* nutrient
* score
* priority
* target per day
* reasons
* suggested food sources

---

## 3) 30–40 Day Recovery Plan

Generate a **personalized 30–40 day food-based meal plan** using:

* nutrient priorities
* diet type
* allergies
* cuisine preference
* budget

Each day should include:

* breakfast
* lunch
* dinner
* 1–2 snacks

For each day calculate estimated:

* protein
* iron
* calcium
* vitamin B12
* vitamin D

Also show:

* daily nutrient totals
* target comparison
* “on target” / “needs improvement” status

Default food system should be **Indian-food friendly**.

---

## 4) Daily Meal Tracking

Create a page where users can log:

* breakfast / lunch / dinner / snacks
* food item
* quantity / serving

After logging meals:

* total daily nutrients
* compare against daily targets
* show progress bars for protein, iron, calcium, B12, vitamin D
* highlight deficits clearly

Example:

* Protein: 42g / 65g
* Iron: 14mg / 18mg
* Calcium: 550mg / 1000mg

---

## 5) Smart Suggestions

If a nutrient target is missed, generate **next-day recovery suggestions**.

Examples:

* low protein → paneer / eggs / curd / dal / soy / chicken
* low iron → spinach + lemon / rajma / dates / roasted chana / eggs / meat
* low B12 → dairy / eggs / fish / fortified foods
* low calcium → curd / milk / paneer / ragi / sesame / tofu
* low vitamin D → food suggestions + sunlight reminder

For each missed nutrient show:

* why it was missed
* 3–5 additions or swaps
* expected improvement if followed tomorrow

---

## 6) Progress Dashboard

Build a dashboard with:

* active recovery nutrients
* today’s intake vs targets
* weekly adherence score
* days tracked / streak

Include charts for:

* daily protein vs target
* iron vs target
* calcium vs target
* B12 vs target
* vitamin D support vs target

Show simple insights like:

* “Protein target met on 5 of last 7 days”
* “Calcium remains consistently below target”
* “Iron intake improved vs week 1”

---

## 7) Optional Lab Comparison

Allow entry of:

* baseline lab values
* follow-up lab values after ~30 days

Show:

* what improved
* what still needs support
* which nutrient recovery areas still need dietary focus

Again, no diagnosis language.
